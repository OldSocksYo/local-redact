# local-redact

本机脱敏办公文档，数据不出这台电脑，不上传，也不部署模型。当前支持 Word（`.docx` / `.doc`）；Excel 等格式后续扩展。

目前主要场景是生态环境检测报告：委托单位、地址、电话、坐标、公章、现场照片、水印这些能认出企业和现场的内容会去掉；检测数值、单位、日期和标准号保留。原稿不会被修改，脱敏结果写到另一个目录。

适合上传前先过一遍编制稿。`.doc` 会用本机的 WPS 或 Microsoft Word 转成临时文件再脱敏，原稿不改，结果一律是 `.docx`。正式盖章发出的 PDF 不在处理范围内。

## 会去掉什么

- 委托单位、受检单位、建设单位、送样单位、客户名称、企业名称、项目名称、项目地址、地址
- 联系人、法定代表人、项目负责人、企业陪同人、电话、采样/检测人员（含结果表人员列）和签字人。结果表里有序号、样品编号时，人员列仍会整列打码
- 项目编号、合同编号、排污许可证号、统一社会信用代码。同一份报告里的编号会换成同一个代号，表和表之间仍能对上
- 经纬度，以及东坐标、北坐标、高斯坐标这类平面坐标列；身份证、银行卡、邮箱、内网 IP、密钥。空格、短横线或括号分组的手机号和固话也会去掉
- 正文、表格、文本框、页眉页脚、脚注、批注、文档属性里的上述内容
- 图片、公章、签名、二维码、图片水印、文字水印、页面背景图。压缩包里的图片文件也会删掉，避免解压后还能看到原图
- 输出的文件名和子目录名。正文或词表里出现过的名称，文件名里同一串字会换成同一个代号

## 会保留什么

- 检测结果、单位、检出限、采样日期
- 标准号和方法依据，例如 `GB 3838-2002`、`HJ 828-2017`
- 邮编、报告编号/文号（含页眉「××字（年）第×号」）、点位名称、点位编号、样品编号，例如 `610300`、`华展环检字（2026）第0002-5号`、`1#排气筒`
- 本机构名称。不想保留时，把全称和简称写进词表

## 第一次准备

在项目目录打开终端：

```bat
cd /d D:\NoteFolder\MineFile\PersonelPro\local-redact
copy lexicon.example.txt lexicon.txt
```

本机需要 Python 3.11，命令用 `python`。依赖是 `lxml`、`pywin32` 和界面用的 `customtkinter`；双击 `redact-gui.bat` / `redact.bat` 时若未安装会自动执行 `pip install -r requirements.txt`，也可手动先装一遍。处理 `.doc` 时还要安装 WPS 或 Microsoft Word。

然后编辑 `lexicon.txt`。一行一个要替换的词：客户全称、简称、厂区地址、文件名里会写的短名称、两三字的人名。`#` 开头是注释。

```text
杭州示例环保科技有限公司
示例环保
文三路1号
张三 => 人员甲
```

`原词 => 代号` 会固定使用你写的代号。只写原词时，工具按本机密钥生成稳定代号，同一名称每次相同。不要把「机构」「报告」这种代号前缀写进词表。

报告里的栏目如果用了别的叫法，例如「被测企业」，把标签加到 `local_redact/fields.py` 的 `FORM_LABELS` 里。

## 图形界面

双击 `redact-gui.bat`（先检查依赖，再用与当前 `python` 同目录的 `pythonw` 开界面，避免 PATH 里其它解释器抢启动），或：

```bat
pythonw -m local_redact.gui
python -m local_redact --gui
```

在窗口里选输入（文件或文件夹）、输出目录和词表，点「开始脱敏」。日志区显示进度；可一键打开输出目录或对照表。

「词表」页可直接编辑、保存 `lexicon.txt`（一行一个词，或 `原词 => 代号`）。开始脱敏前若有未保存修改会先自动保存。

## 每次使用（命令行）

1. 把要处理的 `.doc` 或 `.docx` 放进一个文件夹，例如 `D:\报告原稿`。可以带子目录。`.doc` 转换时会启动一个不可见的 WPS 或 Word，处理完就退出，不会改你正在编辑的文档。
2. 先关掉这些文件。Word 开着时会生成 `~$` 开头的临时文件，工具会跳过它们。
3. 在项目目录执行。结果默认写到项目里的 `output` 文件夹：

```bat
cd /d D:\NoteFolder\MineFile\PersonelPro\local-redact
python -m local_redact D:\报告原稿 --lexicon lexicon.txt
```

只处理一份文件时，把输入换成文件路径：

```bat
python -m local_redact D:\报告原稿\某检测报告.doc --lexicon lexicon.txt
```

也可以用同目录的 `redact.bat`，参数相同：

```bat
redact.bat D:\报告原稿 --lexicon lexicon.txt
```

要写到别的位置时，加上 `-o`，例如 `-o D:\报告脱敏`。

终端会显示处理结果，例如：

```text
词表：D:\NoteFolder\MineFile\PersonelPro\local-redact\lexicon.txt（4 条）
[1/2] 某某公司\某某公司废水检测报告.docx -> 机构_54f79a04\机构_54f79a04废水检测报告.docx
[2/2] 批次\报告13800138000.docx -> 批次\报告[电话已移除].docx
完成 2 个，失败 0 个。
对照表：D:\NoteFolder\MineFile\PersonelPro\local-redact\data\mapping.json
```

`output` 就是脱敏副本。没有敏感内容的文件名会保持原样，例如 `检测报告.docx`。

不要把原稿放进项目目录再拿项目目录当输入，也不要把 `output` 放进输入目录。程序会拒绝「输出目录在输入目录里面」，避免把脱敏结果再处理一遍。

## 上传时带什么

只上传 `output`。

不要一起上传：

- 原稿目录
- `data\mapping.json`。这是对照表，里面有原文，以及原路径和新路径的对应（`files`）
- `data\secret.key`。这是生成本机代号用的密钥，换掉之后代号会变
- 终端里打印出来的原文件名

要回查某个代号对应哪一家、哪一份报告，在自己电脑上打开 `data\mapping.json`。这个文件留在本机。

## 处理不到的情况

- 句子里的两三字人名不会自动全文替换，避免把普通词语误伤。写在「采样人」「审核人」这种格子里的仍会打码。其余短名称放进 `lexicon.txt`。
- 文件名、正文里的简称如果和栏眼里的全称不是同一串字，对不上，需要把简称写入词表。
- 不带「东经 / 北纬 / °」的纯小数坐标，只在坐标类列表头下去掉，例如「经纬度」「坐标」「东坐标」「北坐标」「高斯坐标」。结果和检出限里的数字会保留。
- 叙述句里没有写进词表、也没有出现在栏目标签后面的地址，可能留下。
- SmartArt 里的文字覆盖不完整。整页都是扫描图片时，图片会被删除，这一页的内容也就没有了。
- 嵌入的 Excel 和电子章对象会一并去掉。
- 因子组合、超标情况和大致区域叠在一起，仍有可能猜出企业。去掉地址和坐标之后，这个风险会小一些。
